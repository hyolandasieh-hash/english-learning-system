# English Learning System

A simple personal English learning dashboard that can be opened directly in a browser.

## Files

- `index.html` — The homepage structure for the learning dashboard, including Today's Lesson, Speaking Practice, Vocabulary, Review, and current learning progress.
- `styles.css` — The visual design, responsive layout, cards, buttons, and progress bar styling.

## Run locally

Open `index.html` directly in your browser, or serve the folder with a small local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
